# 日迹 · 手机本地版

> **线上地址：<https://sinwoo666.github.io/daylog/>**
>
> 用 Android Chrome 打开这个地址。注意：`github.com/Sinwoo666/daylog` 是源码页，不能直接安装。

一个只在这台手机上运行的每日记录应用。数据存在浏览器的 IndexedDB 里，不上传、不需要账号、没有服务器。

## 安装

用 Android Chrome 打开 <https://sinwoo666.github.io/daylog/>，然后：

- 设置页会出现「安装到主屏幕」，点它；或者
- Chrome 右上角菜单 →「安装应用」/「添加到主屏幕」。

安装后从桌面图标打开，全屏运行，断网也能用。

## 三个页面

- **今日**：心情/精力、一句话、三件事、随手记、记一笔支出。睡眠、运动、工作、学习、成长、标签都在「更多记录」里，默认收起。
- **账本**：顶部是**本月预算**（默认：房租及水电 2,500 + 吃饭 1,200 + 交通 300 + 日用品社交 500 = 4,500；月收入 6,500；储蓄 2,000），显示本月还能花多少、四类支出的进度；下面是支出明细和记一笔。
- **回顾**：月历、本周回顾、可展开的趋势图。
- **设置**：右上角齿轮。可以改月收入、储蓄目标和四类预算，改完自动保存。

只记录支出，不记收入；没有 6 个月 / 12 个月的长线展示。分类固定为：房租及水电、吃饭、交通、日用品 / 社交及其他。

## 备份（重要）

数据只在这台手机上。清理 Chrome 的「网站数据」、卸载应用、换手机，都会丢失记录。

- 设置 →「导出备份」：生成 JSON，可以直接发到微信/网盘。
- 设置 →「加密备份」：用密码加密后再导出（密码丢了无法恢复）。
- 设置 →「导入备份」：换手机或恢复时使用。
- 超过 7 天没备份，首页会出现提醒。

## 本地预览

在仓库根目录运行一个静态服务（需要 HTTPS 或 localhost 才能注册 Service Worker）：

```bash
npx serve .
```

然后访问 `http://localhost:3000`。

## 部署

这个仓库就是完整的静态站点，推到任意静态托管即可（GitHub Pages / Cloudflare Pages / Netlify）。

GitHub Pages：开启 Pages（分支 `main`，目录 `/`）。`.nojekyll` 已经包含。

## 更新版本

改了前端资源后，把 `sw.js` 里的 `VERSION` 加一（例如 `daylog-v2`），否则已安装的应用会一直用旧缓存。
